Estudante -> PortalReserva: ReservarSala(idSala, data, horario)
PortalReserva -> ServicoReserva: FazerReserva(idSala, data, horario, estudante)
ServicoReserva -> Sala: ChecarDisponibilidade(idSala, data, horario)

alt Sala esta disponivel
Sala --> ServicoReserva: ChecarDisponibilidade():true
ServicoReserva -> Sala: RegistarReserva(idSala, data, horario)
Sala --> ServicoReserva: RegistarReserva(): iDReserva
ServicoReserva --> PortalReserva: FazerReserva():true
PortalReserva --> Estudante: informa que a reserva foi feita com sucesso

else Sala não esta disponivel
Sala --> ServicoReserva: ChecarDisponibilidade():false
ServicoReserva --> PortalReserva: FazerReserva():false
PortalReserva --> Estudante: infroma que a reserva não pode ser feita

end
